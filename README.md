### Anderson's 2023 RPG Project

(this README.md was written by his dad)

The two logic files are game.py and game_classes_and_functions.py. Anderson wrote the Python code by hand. The game uses a library called pygame for input and drawing.

The .tsx files are XML descriptions of the maps and game entities. Anderson created these in a program called "Tiled".

The graphics are a mix of pixel art he created in Aseprite (a pixel art editor) and game art he found on itch.io. I didn't include the image assets only because I wasn't sure about the licenses.

There's also a private YouTube video where Anderson plays through the game and narrates the features. If you're interested to see it, drop me an email. My email is my GitHub username at gmail.
